# Future scope (not in V1)

The following ideas were considered but deliberately excluded from V1. They may be revisited in later versions.

## Harvest integration
- Harvest OAuth authentication
- Automatic download of exports from Harvest API
- Real-time sync with Harvest account

## Migration
- Migration to Clockify
- Migration to Toggl
- Migration to other time-tracking alternatives
- Accounting system integration (QuickBooks, Xero)

## Platform features
- Searchable permanent archive storage
- Cloud backups
- User accounts and authentication
- Subscription billing
- Server-side processing for large archives

## Intelligence
- AI-based file classification
- AI-powered data reconciliation
- Natural language report summaries

## Expansion
- Support for other SaaS products (FreshBooks, Wave, etc.)
- Multi-account comparison
- Team collaboration features

## Enhanced reporting
- Custom report builder
- Scheduled re-checks
- Email notifications
- PDF report export

Each of these would require separate product decisions, privacy review, and engineering effort beyond the V1 scope of local archive verification.
